# Getting Started

New to FlexiRule? Start here. These guides take you from the problem FlexiRule solves to a working rule you can test with confidence. You do not need to learn every action or configuration option before you begin.

FlexiRule is a visual business-logic layer for Frappe and ERPNext. It helps teams make changing business policies visible, testable, and easier to maintain—while custom code continues to provide application capabilities and technical integrations.
