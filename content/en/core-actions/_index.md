# Core Actions

Blocks are the building blocks of your FlexiRule workflows. Each block performs a specific task, such as making a decision, updating a field, or sending an email.

## Data Blocks

- [Set Value]({{< relref "set-value.md" >}}): Update fields and variables.
- [Update Record]({{< relref "update-record.md" >}}): Create or update other records in the system.
- [Query Records]({{< relref "query-records.md" >}}): Find and fetch data from any DocType.

## Logic Blocks

- [Check]({{< relref "check.md" >}}): Evaluate logic and branch your flow.
- [Repeat]({{< relref "repeat.md" >}}): Perform actions for every item in a list.
- [Switch]({{< relref "switch.md" >}}): Choose from multiple paths based on a value.

## Communication Blocks

- [Notify]({{< relref "notify-action.md" >}}): Send emails or system alerts.

## Flow Control

- [Sub-rule]({{< relref "sub-rule.md" >}}): Run another rule as part of this one.
- [Wait]({{< relref "wait.md" >}}): Pause execution for a specific amount of time.
- [Stop / Error]({{< relref "stop-error.md" >}}): Finish the rule or stop with an error message.
