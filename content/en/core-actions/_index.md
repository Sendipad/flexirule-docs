Every automation in FlexiRule is built using "Actions" (logic blocks). This catalog provides detailed guides for each action, focusing on business outcomes and configuration.

### Action Catalog:
- **{{< relref "start.md" >}}**: The entry point for every rule.
- **{{< relref "set-value.md" >}}**: Update fields and variables.
- **{{< relref "check.md" >}}**: Create branches based on conditions.
- **{{< relref "query-records.md" >}}**: Retrieve data from your system.
- **{{< relref "update-record.md" >}}**: Create or modify documents.
- **{{< relref "notify-action.md" >}}**: Send emails or system alerts.
- **{{< relref "repeat.md" >}}**: Process lists of items.
- **{{< relref "process.md" >}}**: Run advanced business operations.
- **{{< relref "wait.md" >}}**: Pause execution for a specific time.
- **{{< relref "stop.md" >}}**: End the rule with a specific status or error.
