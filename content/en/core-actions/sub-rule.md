# Sub-rule

The **Sub-rule** block lets you run one rule from inside another. This is a great way to stay organized and reuse logic you've already built.

## Why Use Sub-rules?
- **Stay Organized**: Instead of one giant, messy map, you can break your process into smaller, "bite-sized" rules.
- **Save Time**: If you have a standard process (like an "Approval Flow") that you use for many different things, you only have to build it once and can call it as a sub-rule whenever you need it.

## How to Use
1. Add a **Sub-rule** block.
2. Pick the existing rule you want to run.
3. **Share Information**: You can choose which data from your current rule should be shared with the sub-rule.
