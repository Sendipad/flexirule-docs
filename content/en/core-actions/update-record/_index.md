# Update Record

The **Update Record** blocks allow you to make permanent changes to the data in your system. While the "Set Value" block is great for changing the *current* document, these blocks are for interacting with *other* records.

## Available Actions

### [Create New Record]({{< relref "create-new.md" >}})
Create a brand new document (e.g., create a "Task" when a "Project" is started).

### [Update Existing Record]({{< relref "update-existing.md" >}})
Modify a record that already exists in the system.
