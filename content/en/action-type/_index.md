# Actions

Actions are the building blocks placed on a rule canvas. Choose an action based on the business operation you need, then open its dedicated guide for configuration details.

## Start with a decision

[Which Action Should I Use?]({{< relref "which-action.md" >}}) helps you choose between flow control, data, document, communication, and process actions.

## Technical terminology

The application uses **Action Type** as the registry/configuration concept. In the user documentation, **Actions** is the preferred term because it describes what users are actually building.
