# Contributing to FlexiRule Documentation

Welcome to the FlexiRule documentation governance area. This section contains the standards, templates, and guidelines required to maintain a consistent and high-quality documentation experience for all users and contributors.

## Documentation Framework

Our documentation is organized into a three-layer model to ensure that information is targeted to the right audience and remains maintainable:

1.  **[Action Documentation]({{< relref "action-documentation-standard.md" >}})**: User-facing guides focused on "What does this action do and how do I use it?".
2.  **Execution Semantics**: Technical specifications detailing "Exactly how does this action behave at runtime?".
3.  **Architecture Reference**: Implementation details for "How is this implemented?".

## Governance Assets

-   **[Action Documentation Standard]({{< relref "action-documentation-standard.md" >}})**: The authoritative specification for documenting any FlexiRule action.
-   **[Deployment Guide]({{< relref "deployment-guide.md" >}})**: Instructions for deploying the documentation to different targets.
-   **[Templates]({{< relref "templates/" >}})**: Reusable starting points for new documentation pages.
