# Terminology Migration Guide

This guide maps legacy FlexiRule terms to the new standardized terminology used in the documentation and future releases.

| Old Term | New Term | Context |
| :--- | :--- | :--- |
| **Assignment** | **Assignment** | Mutating document or context state. |
| **Rule Flow** | **Rule Flow** | The sequential execution of multiple rules. |
| **Execution Context** | **Execution Context** | The sandboxed environment where rules run. |
| **Process Action** | **Extensibility Action** | Actions that run custom code-backed processes. |
