# Getting Started

Welcome to FlexiRule! This guide will help you understand the basics of creating and managing business rules.

## Your First Rule

Creating a rule in FlexiRule involves three main steps:

1. **Define the Trigger**: Determine when your rule should run (e.g., when a Sales Order is saved).
2. **Design the Logic**: Use the **Rule Builder** to map out your business logic.
3. **Activate**: Enable the rule to start processing documents.

## Using the Rule Builder

The Rule Builder is your primary workspace. To add logic to your rule:

1. Open the **Rule Builder** tab on a Rule document.
2. Use the **Action Zone** by hovering over connections or empty space to add new nodes.
3. Configure each node using its dedicated configuration panel.

For a deeper dive into the builder's capabilities, see the [Rule Builder Guide]({{< relref "docs/user-guide/rule-builder.md" >}}).
