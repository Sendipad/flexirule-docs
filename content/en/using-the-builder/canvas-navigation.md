# Canvas Navigation

The Rule Builder is your visual workspace for designing business logic. It provides a drag-and-drop canvas where you can build and see your automation flows.

## Basic Interactions

### Moving and Zooming
- **Move Around**: Click and drag any empty space on the canvas to pan.
- **Zoom**: Use your mouse wheel or the zoom controls in the bottom corner to zoom in and out.

### Working with Blocks
- **Select**: Click a block to select it and open its configuration panel on the right.
- **Move**: Drag a block to reposition it.
- **Delete**: Select a block and press `Delete`. The builder will try to automatically reconnect the surrounding blocks.

### Bulk Actions
You can select multiple blocks at once by holding **Shift** and dragging a box around them. This is useful for moving or copying entire sections of logic.

## Seeing Your Logic Run

One of the best features of the builder is the ability to see your logic in action.

### Visual Path Trace
When you use the **Test Run** feature, the builder highlights the exact path taken during the test in green. This makes it easy to see why a specific action did (or didn't) run.

### Inspecting Results
After a test, you can click on any block to see the data it processed. This helps you verify that variables are being set correctly and conditions are working as expected.
