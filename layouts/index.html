Quick Start

Go from install to executable rule in five steps.

1

Install app

Add FlexiRule to your Frappe bench and site.

2

Open builder

Launch the visual rule builder from Desk.

3

Define trigger

Choose DocType event, scheduler, or callable entry point.

4

Compose actions

Connect conditions, assignments, notifications, and processes.

5

Validate & run

Preview the graph, publish safely, and observe execution.

Core Concepts

Compose rules from a few clear building blocks.

◇ConditionRoute execution using explicit conditions and true/false outcomes. ▶Core ActionsRun assignments, notifications, document updates, and processes. =AssignmentSet document fields and context variables with explicit, ordered assignments. ↻Advanced ProcessExecute registered backend capabilities behind visual configuration.
